# Daekyungjam-Kunekune-Project
대구경북게임잼 11팀 게임 개발 프로젝트 - 쿠네쿠네

## 작업 방법
### 1. 프로젝트 내려받기(Clone)
초록색 [Code] 버튼 ➔ Open with GitHub Desktop을 누릅니다. (GitHub Desktop이 없다면 문의해 주세요.)

내 컴퓨터에 프로젝트를 저장할 폴더 위치를 지정하고 [Clone]을 누릅니다.

### 2. Unity Hub에 프로젝트 추가하기
Unity Hub를 켭니다.

우측 상단의 [열기(Open)] 버튼 옆의 화살표를 눌러 [디스크에서 프로젝트 추가(Add project from disk)]를 클릭합니다.

방금 깃허브 데스크톱을 통해 다운로드받은 유니티 프로젝트 폴더를 선택하고 추가합니다.

이제 버전 아이콘을 확인하고 프로젝트를 열어 작업을 시작하면 됩니다.

### 3. 유의 사항

작업 시작 리포트(Pull): 유니티를 켜기 전에, 무조건 GitHub Desktop을 켜서 상단의 [Fetch origin]을 누르고, 다른 사람이 올린 코드가 있다면 [Pull]을 받아 내 컴퓨터를 최신 상태로 만든 뒤 유니티를 켭니다.

작업 끝 리포트(Push): 오늘 작업이 끝났다면 유니티를 저장하고 끄고, GitHub Desktop을 켜서 내가 변경한 내용을 하단에 적은 뒤 [Commit] 후 [Push]하여 서버에 올립니다.

커밋 메시지는 한눈에 무슨 내용인지 알아볼 수 있도록 작성하면 좋습니다.
