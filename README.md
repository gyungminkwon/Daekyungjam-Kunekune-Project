# Daekyungjam-Kunekune-Project
대구경북게임잼 11팀 게임 개발 프로젝트 - 쿠네쿠네

Unity Version: Unity 6.3 LTS (6000.3.19f1)

화면 비율: 1920 * 1080(16:9)

## 작업 방법
### 1. 프로젝트 내려받기(Clone)

초록색 [Code] 버튼 ➔ Open with GitHub Desktop을 누릅니다. (GitHub Desktop이 없다면 문의해 주세요.)

내 컴퓨터에 프로젝트를 저장할 폴더 위치를 지정하고 [Clone]을 누릅니다.

### 2. Unity Hub에 프로젝트 추가하기

Unity Hub를 켭니다.

우측 상단의 [열기(Open)] 버튼 옆의 화살표를 눌러 [디스크에서 프로젝트 추가(Add project from disk)]를 클릭합니다.

방금 깃허브 데스크톱을 통해 다운로드받은 유니티 프로젝트 폴더를 선택하고 추가합니다.

이제 버전 아이콘을 확인하고 프로젝트를 열어 작업을 시작하면 됩니다.

### 3. 깃허브 유의 사항

1. 작업 시작 리포트(Pull): 유니티를 켜기 전에, 무조건 GitHub Desktop을 켜서 상단의 [Fetch origin]을 누르고, 다른 사람이 올린 코드가 있다면 [Pull]을 받아 내 컴퓨터를 최신 상태로 만든 뒤 유니티를 켭니다.

2. 작업 끝 리포트(Push): 오늘 작업이 끝났다면 유니티를 저장하고 끄고, GitHub Desktop을 켜서 내가 변경한 내용을 하단에 적은 뒤 [Commit] 후 [Push]하여 서버에 올립니다. (커밋 메시지는 한눈에 무슨 내용인지 알아볼 수 있도록 작성하면 좋습니다.)

### 4. 유니티 유의 사항 (중요!)

1. 씬 충돌 방지: 개인 작업용 테스트 씬 만들기 - Assets/Scenes 폴더 안에 각자의 이름으로 된 독립된 씬을 만드세요. 자신의 씬에서만 기능을 구현하고 테스트해야 합니다.

2. 모든 오브젝트 프리팹(Prefab): 테스트 씬에서 캐릭터나 UI를 완성한 후, Hierarchy 창에 있는 오브젝트를 Project 창의 Assets/Prefabs 폴더로 드래그&드롭합니다. 나중에 모든 씬을 합칠 때 이 프리팹 파일을 이용합니다.

3. 스크립트 분리: 예를 들어 플레이어 캐릭터라고 해서 Player.cs 파일 하나에 이동, 햇빛 게이지 계산, 애니메이션 코드를 다 넣으면 안 됩니다. PlayerMovement, PlayerSunGauge, PlayerAnimation 등 컴포넌트 단위로 기능을 잘게 쪼개어 각자 담당한 스크립트만 수정하도록 하세요.

4. 프로젝트 폴더 구조 규칙: Assets 폴더 내부가 어지러워지면 파일 링크가 깨지기 쉽습니다. Assets 폴더 내부에 다음과 같은 폴더를 생성해서 관리하세요. Animations(애니메이션 리소스 및 컨트롤러), Prefabs(모든 오브젝트, UI, 캐릭터 등), Scenes(메인 씬 및 개인 테스트 씬), Scripts(C# 코드 파일들), Sprites(도트 이미지, 원화, 배경 이미지), Sounds(BGM, 효과음)
